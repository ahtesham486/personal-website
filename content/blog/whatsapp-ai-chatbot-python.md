## Why WhatsApp bots matter for business

WhatsApp is where your customers already are. A Python-powered AI chatbot can handle quotes, FAQs, and order flows 24/7 without hiring extra staff.

## Core stack

- **Python** for backend logic
- **WhatsApp Business API** for messaging
- **LLM** (OpenAI, Claude, or local models) for natural replies
- **PostgreSQL or Redis** for session state

## Architecture overview

1. Webhook receives incoming messages from WhatsApp
2. Python backend parses intent (order, quote, support)
3. LLM generates contextual reply
4. Response sent back via WhatsApp API
